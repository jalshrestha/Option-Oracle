# Claude Code — Project Instructions

## Git Workflow
- Never add Claude as a co-author in commits (no `Co-Authored-By` trailer).
- After completing each feature, fix, or meaningful change, commit and push to the **current branch** (never force-push or target main directly).
- Always push to the remote tracking branch that the current branch is already set up to follow.

## Branch Convention
- Work happens on feature branches (e.g. `refactor/code-quality-performance`).
- Pushes go to `origin/<current-branch>` automatically.
